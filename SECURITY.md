# Security Policy

Reconnect may store **sensitive personal information** (case notes, uploaded documents).
Please report security issues responsibly.

## Reporting a Vulnerability
Preferred:
1. Use GitHub **Private Vulnerability Reporting** (Security tab → Report a vulnerability), if enabled.

If that’s not available:
1. Open a GitHub issue titled: **"Security: <short summary>"**
2. **Do not** include real personal data in the issue.
3. Provide steps to reproduce and affected versions.

## Supported Versions
- `main` branch
- Latest tagged release

## Security Defaults
- Local-first SQLite storage
- No telemetry by default
- Binds to localhost by default

Thanks for helping keep Reconnect safe.
